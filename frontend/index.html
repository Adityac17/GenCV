Quick 1-Minute Setup

  1. Open the connected spreadsheet
  2. Click Extensions → Apps Script.
  3. Copy our ready-to-use template code (configured with this Sheet ID).
  4. Click Deploy → New deployment → Type: Web app.
  5. Set Who has access to Anyone.
  6. Paste the generated Web App URL on the left and hit Synchronize!
